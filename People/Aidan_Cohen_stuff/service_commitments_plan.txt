CHART IMPLEMENTATION NOTES (for building in HTML/CSS)
================================================================================

All charts: built in pure HTML/CSS (no JS, no external libs — must print cleanly)

Bar charts:
  - Flexbox column bars, aligned to a baseline
  - Bars are rectangles, fixed width, height proportional to value
  - Value label above each bar (e.g. "21%")
  - Company name label below each bar
  - Y-axis: drawn as a left border on the bar container
  - Y-axis label: rotated 90deg, positioned left of the chart
  - X-axis: drawn as a bottom border
  - Grid lines: optional light gray horizontals at 10% intervals

Line chart:
  - Use SVG — this is the right tool for a line chart in HTML
  - SVG viewBox, draw polyline for each company
  - Client line: stroke-width 2.5, black
  - Competitor lines: stroke-width 1.5, gray (#999 or similar)
  - Data point dots: small filled circles at each data point
  - Value labels at end of each line (right side)
  - X-axis: dates, evenly spaced
  - Y-axis: 0% to 35%, labeled at 5% or 10% intervals
  - Grid lines: light horizontal rules
  - Legend: below or beside the chart

Design rules (apply to everything):
  - Black and white only. No color.
  - Font: Arial/Helvetica for all labels and UI text. Georgia for body copy.
  - No shadows, no rounded corners, no gradients
  - Do not look like AI output — clean, minimal, like a real business document
  - All charts must be labeled: title, both axis labels, legend, units
